# 麻辣湯ストーリー（Malatang Story） — v1.8 開発中

Unity 6000.3.24f1 / URP。下町の商店街にある麻辣湯（マーラータン）の小さなお店を、鍋ひとつから町いちばんの人気店に育てる経営・調理シミュレーションです。レジでの接客（注文の聞き取り・おつり）から調理・提供まで、見下ろし視点でも一人称視点でも遊べます。Mac（マウス・キーボード）と iPhone（タッチ）に対応しています。3Dモデル・テクスチャ・効果音・BGMは、すべて実行時に手続き生成しています。

設計の詳細は `docs/DESIGN.md` を参照してください。

## 遊び方

### 1日の流れ
1. **朝**：天気と本日のイベント（評論家・団体客・セール・お祭り・配信者）、3日目からの朝市を確認し、仕入れ・内装・スタッフ・着せ替えを整えて「営業開始」。
2. **営業（11:00〜20:00、実時間約12分）**：お客さんが歩道から来店してレジに並びます。注文票をタップすると、その場所まで歩いて対応します。
3. **閉店後**：営業レポート（売上・値引き・チップ・報酬・原価・利益・口コミ・できごと）を確認して翌日へ。

### レジでの接客
1. **注文を聞く**：お客さんのせりふ（客タイプごとに口調が違う。海外の旅行者は英語まじり）を聞き、スープ・辛さ・店内／持ち帰りを注文票に書く。間違えると訂正され、接客の印象が下がる。常連の「いつもの」は好みを覚えておく（常連ノートも見られる）。
2. **量る**：セルフ式のお客さんは自分で選んだボウルを持ってくるので、レジ横の秤で量る。
3. **お会計**：現金・QR・カード。現金はお預かりからおつりを紙幣と硬貨（100元〜1角）で組み立てて渡す。足りないと指摘され、多すぎると差額は店の損。

### 満足度とお金
満足度＝品質＋雰囲気＋レジ対応−汚れた席（ベジタリアンに肉を出すと大幅減）。
- 80点以上：チップ（客タイプで気前が違う。芸能人・海外の旅行者は多め、評論家・審査員は払わない）
- 60点未満：値引きを求められ、売上が減る（最大6割）
- 85点以上が続くとコンボ。チップが最大1.5倍

### 調理（厨房の寄り視点）
| 工程 | 操作 | コツ |
|---|---|---|
| ① 具材を取る | 冷蔵ケースの具材をタップ（オーダー式）。セルフ式は客が選び済み | 物理演算でボウルに落ち、毎回違う盛り付けになる |
| ② 量る | 秤（3D）か「秤で量る」 | 重さで値段が決まる。名物メニューは15%増し |
| ③ 茹でる | 空いた鍋をタップ。「時間差で茹でる」なら「今！」の具材から投入 | 具材ごとに茹で時間が違う。全部が同時に緑のゲージに入ると高得点 |
| ④ 湯切り | 網じゃくを上下にドラッグ、または「振る」 | 3〜4回がベスト |
| ⑤ 仕上げ | スープの鍋を長押しで注ぐ。ラー油1回で辛さ+1。薬味の瓶をタップ | 「多め」「抜き」の希望を守る |
| ⑥ 提供 | 「席へ運ぶ」（持ち帰りはレジ） | 食べ終えた席は片付けが必要 |

品質は具材・茹で加減・湯切り・スープ・味付け・速さ・鮮度の内訳で評価され、お客さんのコメントと口コミになります。満足度が高いとチップがもらえ、常連になってくれます。

### やり込み
- **店の物語**：5つの章（鍋ひとつからの出発 → 商店街の顔 → 評判の店 → グランプリへの道 → 伝説の一杯）。章ごとの目標を達成すると賞金と内装テーマが解禁され、物語が進みます（図鑑の「店の物語」タブ、朝の画面に次の目標）。
- **隠しレシピ**：相性のいい具材・スープ・味付けの組み合わせ16種（トマたま麻辣湯、重慶の夜、黄金の麻辣湯 など）。当てはまる一杯は品質が上がり、見つけたレシピは「レシピ帳」に載って、お客さんが名前で注文してくれるようになります（名指しどおりに作ると接客の評価も上がる）。
- **店主スキル**：店舗レベルが上がるたび、グランプリ入賞でもポイント。手際（茹で時間）・接客（忍耐）・目利き（仕入れ値）・愛想（チップ）・名声（来客数）を各3段階まで（経営画面の「スキル」）。
- **内装テーマ**：下町食堂・赤提灯の夜市・モダンカフェ・老舗の茶館・ネオン屋台。壁・床・カウンター・照明・飾りが一新され、雰囲気ポイントが上がります（内装画面の先頭）。
- **日替わりミッション**：1日3つ（例：おつりをぴったり5回渡す、隠しレシピの一杯を2杯出す）。達成するとすぐに賞金と経験値。
- **麻辣湯グランプリ**：14日目から7日ごと。審査員3人の平均点で金・銀・銅賞と賞金。
- **店の格付け**：評判・人気・店舗レベルで星1〜5。
- **お客さん図鑑**：20タイプ。昼・放課後・夜で来る人が変わり、店舗レベルで新しいお客さんが来るようになる。
- **実績**：60種類（v1.6で希少食材の初仕入れ・全6種収集・希少2種入りの一杯を追加）。記録（最高コンボ・おつりぴったり回数・スープごとの最高点・レシピの一杯など）も図鑑で見られる。

### 具材を選ぶ楽しさ
- **通常69種類＋希少6種類の具材はすべて手続き生成の3Dモデル**（葉脈・霜降り・殻の節・ひだ・気泡などの模様テクスチャつき）。生と茹で上がりで色と艶が変わります。
- 具材ごとに**食感**（シャキシャキ・もちもち・ぷりぷり・ふわふわ・つるとろ・コリコリ・ほくほく・やわらか）と**色**、**栄養の役割**（野菜・たんぱく質・主食）とひとことがあり、選ぶ画面・仕入れ画面・**食材図鑑**で見られます。
- **おまかせ注文**（店舗レベル2から）：具材を指定せず「予算」「好きな食感」「野菜たっぷり」「苦手なもの」だけを伝えるお客さんが来ます。冷蔵ケースから自由に選び、**彩り・食感・栄養・重さ**のバランス表示を見ながら一杯を組み立てます。予算どおりの量・希望どおりの組み合わせほど高評価（量が大きくずれる・苦手なものを入れると高得点になりません）。
- 5色以上の具材が入った「虹色の一杯」などの実績、おまかせのミッションもあります。
- **具材の相性**（v1.5）：隠しレシピより小さな「合う2品」の組み合わせが24組（肥牛えのき・豚じゃが・紅白豆腐・過橋米線風 など）。一杯に入っていると1組につき品質+1.5（3組まで）、お客さんもひとこと褒めてくれます。選ぶ画面では、ボウルに入っている具材の相方にハートの印が付き、いま成立している組み合わせと加点が表示されます。初めて出した組み合わせは「相性発見！」として知らせ、食材図鑑に相方が載ります（未発見は「？？？」）。
- **完成の一杯**（v1.5）：茹で上がった一杯を斜め上から撮った写真が完成カードに出て、品質・隠しレシピ・相性をまとめて確認できます。
- **一杯アルバム**（v1.5）：85点以上の一杯を、具材・スープ・味付け・お客さんごと最大12杯まで記録（図鑑の「一杯アルバム」タブ）。点数の高い順で、同点なら新しい一杯が上に残ります。

### スープと朝市（v1.6）
- **スープの質感**：6種類それぞれのスープ面を手続き生成し、縁の濃淡・濁り・脂のムラ・油玉を表現します。麻辣は広い迷彩状の斑点ではなく、薄い赤橙の油膜に細かい油玉と控えめな濃淡が重なる表現です。辛くするほど赤いラー油の膜が増え、選んだ薬味が浮かびます。調理中の一杯・スープ鍋・完成カードの写真で同じ仕組みを使います。完成カードは一杯の写真をカード幅いっぱいに表示し、「品質内訳」で湯切りを含む全7行へ移動できます。提供ボタンはスクロールの外に固定しています。
- **朝市**：3日目から、その日だけ仕入れられる希少食材が1種類登場します。1日5個限定の高級品で、通常の売上による解禁やまとめ仕入れ・各種割引とは別枠です。店舗ごとの固定シードで日替わりとなり、6日ごとに全6種類がひととおり登場します。価格は1個14〜28元（5個70〜140元）で、通常食材の最高額であるホタテ6.4元／個の約2.19〜4.38倍です。
- **希少食材**：松茸・霜降り和牛・鮑・車海老・金華ハム・黒トリュフの6種類。希少食材入りの一杯は品質+3（種類数・個数による重複加算なし、品質100点と既存のおまかせ上限を維持）となり、お客さんもひとこと反応します。入手・提供の記録は保存され、食材図鑑の希少区分と実績で収集を楽しめます。未入手の食材は「？？？」表示です。
- **希少の利用範囲**：購入後は手動調理と図鑑で利用できますが、通常の客注文・スタッフやおまかせの自動選択・旬・旬ミッションの候補には入りません。希少入りの一杯を名物に登録することはできますが、その名物は客の注文候補から除外されます。通常食材の在庫がない場合も希少で代替しません。
- **描画の準備と復旧**：全36スープテクスチャと標準トッピング24メッシュをワールド生成前に共有キャッシュへ準備します。今回のMac計測で事前生成処理は約726ms、共有資源の算定バッファ容量は約13.2MiBです（アプリ全体のメモリ量や実機起動時間ではありません）。保存データの注文・アルバムに含まれる未知や欠損の薬味IDは読み込み時に除去し、描画側も未知IDを無視します。

### 季節と旬
- 春・夏・秋・冬が14日ずつめぐります。街路樹（桜・深緑・紅葉・枯れ枝）や舞う花びら・落ち葉・雪、店先の飾り、日差しの色が季節で変わり、季節ごとに好まれるスープ（春は白湯、夏はトマト、秋はきのこ、冬は麻辣）が人気になります。
- **旬の食材**は1週間ごとに替わり（朝の画面と仕入れ画面に表示）、仕入れが25%安く、お客さんがよく頼み、旬の具材が入った一杯は満足度が上がります。旬のミッションもあります。

### 営業の評価
閉店後のレポートで、その日の営業を S〜D で評価します（満足度の平均・取りこぼし・値引き・提供数から）。直近7日の営業利益と評価をグラフで見られます。

### キャラクター
店主・お客さん・スタッフは、髪型11種・目5種・眉3種・ひげ・そばかす・靴の色などの組み合わせで一人ひとり違う顔になります。気分で表情（にっこり・への字・怒り・汗）が変わり、歩くと頭が弾み、待っている間はきょろきょろします。店主は着せ替え画面で16項目を選べます。

### 経営と成長
- **店舗レベル（最大15）**：提供するほど経験値が貯まり、スープ（6種）・薬味（8種）・家具・スタッフ・設備が解禁されます。
- **食材（通常69種類＋希少6種類）**：通常食材は累計売上で順次解禁し、5個単位で仕入れます。希少食材は朝市限定です。3日で鮮度切れ（冷蔵庫で+1日）。在庫は注文ごとに確保され、二重販売されません。
- **内装**：テーブル（2〜4席）・装飾・壁飾りをグリッドに配置。雰囲気ポイントが客の忍耐・満足度・チップに効きます。入口と通路はふさげません。
- **スタッフ**：ホール係（配膳・片付け）、レジ係（受付・計量）、調理補助（茹で・仕上げ）。研修で速く正確になります。調理中の注文は「自分で引き継ぐ」こともできます。
- **設備**：調理鍋（最大4台）、保管棚、業務用冷蔵庫、高火力コンロ、客席の拡張（2段階）。
- **名物メニュー**：品質75点以上の一杯を登録（最大3品）。売れるほど注文が増えます。
- **常連客**：好みを覚えていて、親密度が上がるとそれぞれの物語を話してくれます。

## 保存

30秒ごと、会計・調理の区切り、閉店、翌日開始、中断、バックグラウンド移行時に自動保存します。保存先は `Application.persistentDataPath/malatang-save.json`（Mac では通常 `~/Library/Application Support/MalatangStory/Malatang Story/`）。

一時ファイルに書き切ってから主保存・バックアップを原子的に置換します。8 MiBを超える保存を読み込みません。非致命的な読み込み失敗はバックアップから復旧し、両方が読めない場合は日時つき `.corrupt-*.json` に退避してタイトルで通知します。金額・経験値・家具・件数・表示文字を復元時に正規化します。チェックサムは破損検知用で、改ざん防止機能ではありません。v0.1（形式 v1）・v1.0（形式 v2）・v1.1（形式 v3）以降の保存データは読み込み時に最新形式（v10）へ移行します（v1.1 からは物語・レシピ・スキル・テーマが初期状態で始まります）（v1 の営業途中のデータは返金して閉店扱い。v2 の営業途中の未会計の注文は、厨房の秤で従来どおり会計できます）。v1.4 以前の保存データでは、相性の記録とアルバムが空の状態から始まります（盛り付け済みの一杯は相性を復元）。v7以前の保存データでは、希少食材の入手記録と朝市の購入記録が空の状態から始まります。朝市で購入した食材は翌日も通常の鮮度管理で保持されますが、当日の仕入れ権は翌日に持ち越せません。アプリより新しい形式の保存データは、復元にも上書きにも使いません。

## 開発用ツール

| コマンド | 内容 |
|---|---|
| `Tools/compile-check.sh` | Unity を起動せずに全スクリプトを型検査（約2秒） |
| `Tools/compile-core-tests.sh` | 中核ロジックと EditMode テストだけを型検査 |
| `Tools/compile-files.sh <files>` | 指定ファイルだけを型検査 |
| `Tools/run-tests.sh EditMode` / `PlayMode` | Unity でテストを実行して要約を表示 |
| `Tools/smoke.sh` | Mac 開発ビルドを作り、自動プレイで主要画面（相性の印・完成の一杯・全6スープの寄り写真・朝市・希少食材図鑑・アルバムを含む）を撮影（画面が消灯していると描画待ちで止まるため `caffeinate -d Tools/smoke.sh` で実行）（`Builds/Verification/`） |

コミット前に `git ls-files` を確認し、秘密情報・`*.zip`・Builds・TestResultsが含まれないことを確認してください。スモーク出力先は既存ディレクトリに限定し、`..` を含むパスを拒否します。

Unity メニュー `Malatang Story` には、プロジェクト再設定（URP・マテリアル雛形・ポストエフェクト）、Mac ビルド、iOS エクスポートがあります。
