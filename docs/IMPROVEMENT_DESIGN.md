## G の設計（実装前確認用）

- 保存形式は v10。既存フィールド・enum値は維持し末尾に追加。v1–v9は移行時に新項目だけ既定値を設定。既存店舗・進行を保持。
- G1/G4: Core の営業時間別来客係数と客の要望を拡張。価格・ラッシュ・仕入れ変動はゲーム用定数。
- G2/G3: Core に朝の仕込み状態、品質、命名可能なスープ配合を追加。朝画面で仕込み／スタッフに任せるを選択し、料理の品質に小さな加点。
- G5/G6: 常連の選択会話とスタッフの個性・疲労・やる気。スタッフは役割以外の永続IDを持ち、既存の役割別検索を複数雇用に対応させる。既存スタッフには固定の移行IDを設定。
- G7: 出前、祭りの屋台、競合イベント、物語完了後の引き継ぎ開始。通常営業とは明示的に切り替え、引き継ぎ元のセーブを保全。
- G8: 日替わり固定シードのスコアアタックと週替わり制約。通常営業の進行と独立した最高記録を保持。
- G9/G10: 価格と需要、日替わり原価、まかない、実績・図鑑に応じた外見報酬。課金・外部通信なし。
- 検証: 各モジュールの境界値と同一シード再現性、v1–v10移行、途中保存からの再開、報酬の二重受領防止、UI操作とスモーク。
